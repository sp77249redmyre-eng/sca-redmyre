A/C Temperature Request

Choose a target temperature directly using the Temperature Adjustment slider.

How it works

Request a specific target temperature

The A/C request screen now uses the current setpoint as the starting point. There is no separate “Too Hot” or “Too Cold” selection.

TENANT
Important: Temperature requests are made in 0.5°C steps. A single request can move the target by a maximum of ±2.0°C from the live Current Setpoint, while the system remains within 18°C–25°C.

1
Select Floor and Tenancy

The Temperature Adjustment control is enabled after the floor and tenancy are selected.

2
Check Current Setpoint

The live Current Setpoint is read from the selected tenancy. The available range is Current Setpoint ±2.0°C, limited to 18°C–25°C.

3
Move the slider

Use the slider, or the − / + controls, to choose the target in 0.5°C increments.

4
Check the Request button

The button shows the exact target, for example Request 21.0°C →. If the target equals the Current Setpoint, the button is disabled.

5
Submit the request

Before submission, the system checks the live Current Setpoint again so the ±2.0°C limit is not based on stale screen data.

6
Wait before another adjustment

Temperature adjustment requests are limited to one request every 30 minutes.

What happens after a report?
The BMS uses different responses depending on whether the vehicle is a registered resident vehicle or a visitor vehicle.
🏠 Registered resident vehicle
When the vehicle matches a registered resident vehicle, the system can send an automatic warning email asking the owner to move the vehicle.
Automatic emailPlease move your vehicle
🚗 Visitor vehicle
Visitor vehicles do not have resident contact details. The first response is a warning sticker; from the 3rd violation, a red strong-adhesive sticker is used.
1–2 · Warning sticker3rd+ · Red sticker

A/C Temperature History

See building-wide temperature request trends and patterns.

How it works

Understand the A/C History screen

This page helps you understand temperature requests across the building.

TENANT

What this page shows

The A/C History page is a building-wide analysis dashboard. It shows patterns from temperature-related requests recorded across Redmyre House.

Important: This is not your personal request history. The results are grouped across the building.
1

Read the building-wide A/C picture

Start with the three summary areas at the top of the page.

⌂
Highest Request Floor Which floor has the most requests?

Shows the floor where the highest number of temperature requests has been recorded.

↕
Hot vs Cold Are requests mainly Hot or Cold?

Compares requests where people reported that the area was too hot or too cold.

◷
Peak Request Time When are requests most common?

Shows the time of day when the most temperature requests were recorded.

2

Compare requests by floor

The floor view shows where temperature requests are concentrated across Levels 1–6.

How to read the floor view

Each row represents one building level. The bar gives a quick visual comparison of the number of temperature requests recorded for each floor.

  • Longer bar: more requests recorded.
  • Shorter bar: fewer requests recorded.
  • The number at the end of the row is the recorded request count.
